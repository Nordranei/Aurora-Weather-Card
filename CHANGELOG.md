# Changelog

All notable changes to this project will be documented in this file.

This project follows Semantic Versioning.

## [1.2.0] - 2026-08-10

### Added
- Aurora Dynamic Atmosphere
- Animated Northern Lights night atmosphere
- Day atmosphere
- Seasonal atmosphere support
- Expanded-view weather information tiles
- Wind direction indicators
- Code-based inline SVG metric icons

### Changed
- Refined compact and expanded layouts
- Improved graph spacing and readability
- Improved precipitation scaling
- Wind values normalized for display in m/s
- Responsive refinements for desktop, tablet and mobile
- Updated documentation for the current 24 / 48 hour forecast options

### Compatibility
- Preserves the public card type: `custom:aurora-weather-card`
- Preserves the HACS distribution filename: `aurora-weather-card.js`

## [1.0.1]

### Fixed
- Fixed fog icon rendering on Windows browsers.
- Updated README feature list.
- Removed outdated 72-hour forecast references.

## [1.0.0] - 2026-08-09

### Added
- Initial public release
- Temperature graph
- Precipitation graph
- Wind graph
- Wind gust graph
- Hourly weather forecast
- 24 and 48 hour forecast
- Expandable detailed view
- Visual configuration editor
- Responsive layout
- Light mode support
- Dark mode support
- Aurora Static theme
- Aurora Dynamic foundation

### Fixed
- Card registration in Home Assistant
- Light mode rendering
- Legend layout
- Responsive scaling
- Weather icon rendering
- Precipitation axis
- Wind graph scaling
